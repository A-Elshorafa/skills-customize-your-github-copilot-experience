# 📘 Assignment: Interactive Frontend Dashboard

## 🎯 Objective

Build an interactive student assignment dashboard using HTML, CSS, and JavaScript. You will practice DOM manipulation, event handling, and data-driven UI updates in the browser.

## 📝 Tasks

### 🛠️ Build the Dashboard Layout

#### Description
Create the page structure and styling for a dashboard where students can view, add, and manage assignment items.

#### Requirements
Completed program should:

- Create a page with a heading, an input form, and a list area for assignments
- Style the page so each assignment appears as a card with clear text and spacing
- Include labels or placeholders so users understand each form field


### 🛠️ Add Interactivity with JavaScript

#### Description
Use JavaScript to let users add assignments, filter by completion status, and mark assignments as complete.

#### Requirements
Completed program should:

- Add a new assignment card when the user submits the form
- Include a way to mark an assignment as complete and visually update its state
- Add a filter control to show `All`, `Active`, or `Completed` assignments
- Keep all UI updates dynamic without reloading the page
