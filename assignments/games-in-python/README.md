
# 📘 Assignment: Build a Hangman Game in Python

## 🎯 Objective

Create a complete Hangman game that helps you practice core Python skills such as loops, conditionals, strings, lists, and user input handling.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description
Create the basic game setup so the program can choose a hidden word and prepare the game state.

#### Requirements
Completed program should:

- Define a list of possible words.
- Randomly choose one word for each game.
- Create a way to display hidden letters using underscores.
- Set a maximum number of incorrect guesses.

### 🛠️ Implement the Guessing Loop

#### Description
Build the main game loop where the player enters guesses and the game updates after each turn.

#### Requirements
Completed program should:

- Ask the player to enter one letter at a time.
- Check whether the guessed letter is in the hidden word.
- Reveal correctly guessed letters in the displayed word.
- Decrease remaining attempts for incorrect guesses.
- Prevent duplicate guesses from causing incorrect game behavior.

### 🛠️ Finish Game Logic and Output

#### Description
Add clear end conditions and messages so players know whether they won or lost.

#### Requirements
Completed program should:

- End the game when the full word is guessed.
- End the game when no attempts remain.
- Display a win message when the player succeeds.
- Display a loss message and reveal the correct word when the player runs out of attempts.
- Keep output readable and student-friendly throughout gameplay.
